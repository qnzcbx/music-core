# ASCII海洋来源

核心数学、物种、World模拟和AsciiRenderer来自 [stackedlol/ascii-sharks](https://github.com/stackedlol/ascii-sharks)。

保留了原有注释、鲨鱼形体/超采样、脊椎跟随、群体运动、捕食/重生、速度、字符密度与光照采样。math/species/world增加来源标记和显式.ts导入；renderer将颜色映射为浓淡墨色，将字符改为简谱数字、点线、音符和升降记号。
