# 09 QQ解析审核

2026-11-06，完成旧实现三条路线复核、QQProvider有序配置、禁用策略、总预算与固定样本对照。**没有恢复三条外部取链适配器，没有取得额外路线的当前可播证据，不能宣称覆盖率提升。**

默认只有official。服务端MUSIC_CORE_QQ_RESOLVER_ORDER可配置已知标识的顺序及省略某条路线；vkeys/qqovo/tang目前均不具备运行资格，配置不能自行解禁。所有配置项都不可用时返回capability_unsupported。重复、空项或未知标识在初始化时明确拒绝。

外部服务的访问条件与录音验证依据尚未确认。旧实现曾接受URL-only结果并用时长作筛查；这不能证明平台授权或录音身份。当前实现不采用该准入方式。外部主页查询失败只说明当次访问未成功，不能据此认定服务下线。

原生基线与审核后策略均对两个固定样本取得2/2媒体、身份回显匹配及4096字节探测，实际路线均official。QQ两种配置的真实播放、暂停、Seek与重开通过。额外路线目标验收未达成，原因和限制见[路线说明](QQ-Resolver-Routes.md)与[验证记录](Verification-Resolver-Audit.md)。

无新增依赖；未修改公共模型、Store/Lease/RecoveryPlayer或其他Provider。来源顺序和默认来源配置保持不变。外部路线仍禁用，记录范围限于路线审核和有限样本验证。
