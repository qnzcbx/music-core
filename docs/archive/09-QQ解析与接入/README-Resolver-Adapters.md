# 09 QQ解析器适配

2026-11-06，已实现独立vkeys、qqovo、Tang适配器，接入QQProvider现有有序编排、25秒总预算和取消链。与4D不同，这次交付实际请求构造、响应解析、身份等级、Session/HMAC签名及有限媒体校验代码和离线测试，不是只有配置字符串。

默认仍为official。三条外部路线当前状态均为“已实现，当前使用条件不足”：公开入口已有限请求且均HTTP200，但页面未给出足以确认本次API取链使用条件的信息。没有向外部服务提交歌曲，没有外部真实媒体或浏览器成功证据；不能宣布覆盖率提高，也不能称服务已经失效。

vkeys/qqovo URL-only结果为request_bound，不因缺少回显被当作协议失败，也不会直接发布为已确认录音；Tang核验MID与非空元数据，排除伴奏和翻唱，并支持对可信预期名称/歌手的额外核对。已接入的正式发布路径只接受confirmed结果，并在目标校验及有限音频探测后创建原ResolvedMedia。

389项pytest通过（原352保留、新增37），17项Node及8项受控恢复场景通过；四来源真实播放、Seek、稳定身份重开及引用清理均通过。没有新增依赖或修改公共模型、媒体生命周期、其他Provider。

详见[协议与资格](QQ-External-Resolvers.md)、[验收](Verification-Resolver-Adapters.md)。下一步需取得可核验的当前服务使用条件，再对同一合法样本逐条实测；request_bound需要独立元数据或人工录音确认后才能提升等级。
