# 01 核心架构 — 实现范围与研究来源

Music Core 使用独立的 Python/FastAPI 后端和 Vue 客户端。四个音乐来源分别实现为 Provider，统一返回本项目的曲目身份与媒体结构。播放、下载、歌词和转码均由项目内模块及 API 契约维护。

## 研究来源

开发期间查阅过公开音乐客户端库中与来源协议相关的实现，仅用于理解请求参数、响应字段和调用顺序。该库仅作为研究来源；Music Core 不依赖或导入它，不使用其账号、令牌、会话数据或运行产物。Provider、Resolver 与 API 由本项目维护。

## 许可边界

依赖及版本见 `server/pyproject.toml` 和锁文件。第三方研究来源的许可不自动适用于 Music Core；项目整体分发许可尚待确定。FFmpeg 的分发条件取决于实际使用的构建。
