## 请求、验证与生命周期

下载请求新增可选 quality：auto / standard / high / lossless，缺省 auto；通过原 ResolveOptions(purpose=download, providerQualityId=目标) 传入 Provider。普通播放不传下载目标，沿用原首个合格结果及原有4KiB探测。显式下载目标在原串行循环内核对，不满足使用既有 media_unavailable，继续允许的后续路线；权限错误不继续，原25秒解析预算、取消传播及目标安全检查保留。

字节探测上限64KiB：MPEG帧解析 MP3 编码 / 帧码率 / 采样率，ID3标签本身不证明编码；VBR头不伪造平均码率。FLAC需合法 STREAMINFO 才确认无损编码与采样率；MP4在实际 stsd 音频样本框中区分 AAC / ALAC，AAC平均码率来自 esds DecoderConfigDescriptor，不以 m4a 后缀判无损。没有可读结构就保留未知，Ogg等未扩展格式不伪造品质。

当前谨慎目标边界：标准为已证实有损且码率不高于160kbps；高品质为约192kbps以上（允许2%编码元数据误差）或已证实无损；无损必须确认 FLAC / ALAC 无损编码。平台档位参数是请求，最终仍需满足字节目标；未实现或码率未知的明确档位不伪装可用。FLAC只证明现有文件编码，无从证明录音上游从未经过有损转换。有限前缀无法证明全曲每帧恒定码率或检测“假无损”历史。

DownloadManager保持并发2、队列、取消、总下载超时、大小上限、进度、临时文件清理、文件头与响应/磁盘长度核对、同名不覆盖、硬链接原子发布、完成文件索引。只在原发布前增加实际品质核对，不满足就失败并清理part；请求无损不会保存MP3并宣称成功。任务保留 quality 和 actualMedia（实际编码、容器、采样率、码率、大小），失败重试保留quality并重新解析，不复用过期地址。

## 弹窗与请求成本

弹窗只展示歌曲、歌手、品质、实际编码/格式、已确认码率/采样率及响应大小；内部Resolver、API代码、耗时和地址不显示。首开只检测自动，用户选其他档位时按需检测，未检测项标“选择后检测”，不是四项都默认可用。明确不可用、访问条件不满足、超时与网络错误均有简短反馈，确认按钮不会放行未验证项。无需预先播放；本地文件不会打开在线弹窗。

新增 POST /api/downloads/options。仅缓存公开检测摘要，最多32项、最长30秒且不超过已知媒体有效期，不缓存URL或下载凭据。可复用Provider本次已验证的媒体信息，避免重复前缀读取；重复打开由后端短缓存减少重复取链。确认下载仍必须新解析和最终字节核验。

检测最大27秒，客户端30秒；关闭/换歌会abort前端请求并由后端断连监测取消未完检测。前端代次隔离保证旧请求不覆盖新歌或新品质。没有通用缓存框架或第二套下载器。不同品质可以保存不同任务，同录音同品质不会重复创建已有任务，缺失完成文件时允许重新创建。成功/失败通知及下载状态图标继续使用原任务和文件快照。

## 测试、兼容与剩余限制

前端44项测试通过；类型检查与生产构建通过，约515KB主包既有告警保留，不调整阈值。后端589项收集、588通过 / 1跳过，跳过为既有Windows符号链接权限；包括既有四来源、权限、安全、下载并发/取消/超时/重试/原子发布、歌词、本地文件、Lease与恢复回归，及14项品质参数 / 真实字节 / 不静默降级 / 后续路线 / 明确拒绝 / 缓存 / 取消预算测试。没有重复编写已有下载完整性测试。

新增依赖：无。公共下载请求/任务是兼容性扩展，MediaRepresentation新增可选sampleRateHz；新增下载检测端点并更新前端类型和契约断言。未改变播放Open/Lease/Range协议或唯一Audio模型。

限制：64KiB中没有可读元数据、VBR平均码率无法确认、未知容器编码时相应字段未知，明确目标可能保守不可用；不是猜后缀或扩大请求枚举。短缓存不能保证未来签名地址有效，最终下载会重新解析校验。第三方可访问与请求绑定不等于独立身份认证或永久版权/下载授权；明确访问拒绝不绕过。本次没重跑四平台所有曲目或真机Safari，触摸为Chromium仿真。

常用8001旧Core进程没有停止，以免打断用户当前播放；该进程尚无新options路由。需要重启目标项目后端加载新模型/路由，刷新前端后即可使用。隔离验收服务已收尾。

阶段 20保留事项：FLAC→MP3/AAC转换、重新编码压缩、空间优化、标签与封面嵌入、响度标准化。阶段 19没有偷偷进行这些工作。
