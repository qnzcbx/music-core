## 安装与接入

Stage B 正式产物已复制到仓库内 `web/vendor/ink-breath-0.2.0.tgz`，未被 Git 忽略，目前为待纳入版本管理的新文件。package.json 和 pnpm-lock.yaml 均使用相对 `file:vendor/ink-breath-0.2.0.tgz`，锁文件包含完整性摘要。`pnpm install --frozen-lockfile` 通过，无绝对路径、源码 alias 或全局链接；克隆复现需一同提交该 tgz。本次未暂存或提交。

HomeView 引用薄包装 `features/home/components/HomeInkBackground.vue`。包装只处理主题、偏好、尺寸、失败回退与场景参数，异步加载正式 `ink-breath/vue` 并显式导入 `ink-breath/vue.css`，没有复制绘制算法或创建另一套 RAF/ResizeObserver。公开入口、SFC 编译、类型检查和生产构建均通过。依赖树确认与宿主共用 Vue 3.5.43，无重复运行时。

参数为 lotus-fish、medium、auto renderer、autoInk=true、active=true。原任务要求关闭交互、空文字，用户在实施过程中明确要求恢复全部交互，因此最终 interactive=true、text 绑定首页搜索草稿。GlobalSearch 新增 draftChange 事件，经 HomeSearch 转发至 HomeView，不改变共享搜索状态。组合输入结束后才同步，清空输入清空水墨字。空白区点击落墨、划动扰动与淡墨由包内原有实现处理；输入框、按钮继续优先接收操作。

## 生命周期和主题

背景 absolute 限定在 HomeView 的明确尺寸内；前景保持 z-index=1，没有修改 AppShell 的层叠体系或 body/html。首页保持既有单屏布局，下载页滚动可到 scrollTop=300。移动导航与播放器仍由原 AppShell 管理。

主题来自已有 APPEARANCE 的 effective 与 subscribe，卸载取消订阅。Light/Dark 通过 prop 原位更新，主题切换未新增 WebGL 上下文。RouterView 没有 KeepAlive，离开首页即卸载并由包 destroy，返回重新挂载。可见性暂停继续由 Core 负责，没有增加宿主动画时钟。

减少动态效果时 active=false、autoInk=false，并使用 canvas renderer 呈现静态纸面。避免冷启动时尚未绘制的 WebGL 不透明黑画布遮挡首页；不播放鱼荷动画，切换偏好会受控重建一次 renderer。quality 始终固定 medium。

初始化 error 时回退宿主底色；异步模块加载失败也保留首页搜索与导航。

## 浏览器验证

Python Playwright + Chromium，访问本地 Vite 5174、Core 8001。实际渲染环境为 ANGLE Vulkan SwiftShader Device (Subzero)，属于软件渲染；移动视口不等于实体手机性能证明，未虚构 FPS。

- 已查看 1440×900、768×560、390×844 的浅色/暗色截图。鱼荷比例正常，无严重裁切、白边或透明断裂。桌面底部部分荷叶出画沿用原构图。
- 首页搜索可提交并进入搜索页，返回首页正常。六次往返后离页画布和待执行 RAF 均为 0。切换主题的上下文创建数保持 1。
- 四次资源专项：首页有 47 个被跟踪 GPU 对象、1 个 ResizeObserver、1 个引擎 AbortSignal，每次离页三者均归零。计数来自验收脚本包装浏览器 API，非长期泄漏保证。
- 真实点击下载列表 M4A，由原生 Audio 解码播放。进入/离开首页 Audio 保持同一实例，进度连续增加，没有新增 Playback Open；Seek 到 30 秒后继续推进。没有宣称全部在线来源或全曲库回归。
- 禁用 WebGL 时自动降级 CanvasFallback，已查看截图；模拟绘图初始化全部失败仍可输入搜索。阻断包模块请求后仍可填写并提交搜索。
- Chromium 移动模式验证触摸聚焦输入；未测试实体手机性能。原有页面滚动正常。
- 用户确认交互后，临时浏览器诊断确认输入“清风”同步引擎 phrase、1 次点击 dropInk、10 次 erase 调用；已查看含水墨字截图。清空、搜索提交通过。诊断仅拦截验收浏览器响应，没有修改包或生产源码。

截图与一次性验证脚本位于 Git 忽略的 `.runtime/verify-ink/`，机器证据归档为 results.json、resources.json、interaction.json。

## 限制与后续优化

用户发现输入时鱼荷似乎刷新。代码审计确认 InkEngine.setText 无条件调用 createMotif，清空意象层、重新 setPhrase，并添加事件墨；没有重建 WebGL 引擎。固定 lotus-fish 时，建议下一版本仅更新字形，意象和尺寸变化时才重建场景，并增加相应回归验证。本期按要求保持独立引擎只读，没有在宿主绕过公开 API 或修改打包产物。

真实 GPU、实体手机及长期资源曲线尚待补测。SwiftShader 上操作和音频验证通过，但不能推出硬件帧率。减少动态效果冷启动呈现静态纸面。
