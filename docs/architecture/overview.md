# 当前架构概览

## 组成

- `server/app/`：FastAPI 服务、Provider、公共模型、媒体解析与传输、下载、品质检测、转码、歌词和本地文件能力。
- `web/src/`：Vue 客户端，含搜索、单一播放器状态、播放队列、同步歌词、下载界面及本地音频播放。
- `server/tests/` 与 `web/tests/`：自动化测试。长期手动在线及浏览器验证工具按用途列在 [后端验证说明](../../server/README.md)。

## 关键数据流

搜索请求按 providerId 路由到四个独立来源适配器（酷我、QQ、网易云、咪咕），返回统一曲目身份。在线播放由稳定身份重新解析媒体，MediaStore 持有私有上游信息，PlaybackLease 管理客户端会话；客户端共用单个 Audio，并由播放器协调队列和有限恢复。下载任务独立于播放 Lease，按用户所选来源和品质解析、流式写入；转码由 FFmpeg 路径处理。歌词通过独立 API 获取并由客户端按播放时间同步。

## 边界

Provider 与 Resolver 负责来源协议；公共模型和 API 负责跨模块契约；MediaStore/Lease 负责播放资源生命周期；Vue 播放器拥有客户端播放、队列和恢复协调状态。`docs/archive/` 是按本项目新编号组织的历史验收资料，阶段结论需按时间理解，当前行为以源码和本文为准。
